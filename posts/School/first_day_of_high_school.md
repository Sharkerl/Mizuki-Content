### 常用三角函数公式

$\sin(\pi + \alpha) = -\sin(\alpha)$ <br>
$\cos(\pi + \alpha) = -\cos(\alpha)$ <br>
$\tan(\pi + \alpha) = \tan(\alpha)$ <br>


$\sin(\frac{\pi}{2} - \alpha) = \cos(\alpha)$ <br>
$\cos(\frac{\pi}{2} - \alpha) = -\sin(\alpha)$ <br>
$\tan(\frac{\pi}{2} - \alpha) = -\cot(\alpha)$ <br>


$\sin(A + B) = \sin(A)\cos(B) + \cos(A)\sin(B)$ <br>
$\cos(A + B) = \cos(A)\cos(B) - \sin(A)\sin(B)$ <br>
$\sin(A -B) = \sin(A)\cos(B) - \cos(A)\sin(B)$ <br>
$\cos(A - B) = \cos(A)\cos(B) + \sin(A)\sin(B)$ <br>


$\sin2A = 2\sin(A)\cos(A)$ <br>
$\cos2A = \cos^2(A) - \sin^2(A) = 1 - 2\sin^2(A) = 2\cos^2(A) - 1$ <br>
$\tan2A = \frac{2\tan(A)}{1 - \tan^2(A)}$ <br>


$\sin\frac{A}{2} = \sqrt{\frac{(1 - \cos(A))}{2}}$ <br>
$\cos\frac{A}{2} = \sqrt{\frac{(1 + \cos(A))}{2}}$ <br>
$\tan\frac{A}{2} = \frac{1 - \cos(A)}{\sin(A)} = \frac{\sin(A)}{1 + \cos(A)}$ <br>

### 和差化积公式

$\sin(a) + \sin(b) = 2\sin(\frac{a + b}{2})\cos(\frac{a - b}{2})$ <br>
$\sin(a) - \sin(b) = 2\cos(\frac{a + b}{2})\sin(\frac{a - b}{2})$ <br>
$\cos(a) + \cos(b) = 2\cos(\frac{a + b}{2})\cos(\frac{a - b}{2})$ <br>
$\cos(a) - \cos(b) = -2\sin(\frac{a + b}{2})\sin(\frac{a - b}{2})$ <br>
$\tan(a) + \tan(b) = \frac{\sin(a + b)}{\cos(a)\cos(b)}$ <br>

### 积化和差公式

$\sin a \sin b = -\frac{1}{2}[\cos(a+b) - \cos(a-b)]$  <br>
$\sin a \cos b = \frac{1}{2}[\sin(a+b) + \sin(a-b)]$  <br>
$\cos a \cos b = \frac{1}{2}[\cos(a+b) + \cos(a-b)]$  <br>
$\sin a \cos b = \frac{1}{2}[\sin(a+b) - \sin(a-b)]$  <br>
